# FloatTranslate v2.0 — 零弹窗·点击悬浮球直接全屏原位翻译

针对上一版的问题进行了彻底重构：
1. **去掉中间弹窗与手动输入框**：点击悬浮球不再弹出占屏幕中间的输入面板，也不会让你手输或手动框选。
2. **点击即自动读取/自动全屏截图 + 原位覆盖翻译**：
   - **轻点悬浮球**：直接自动抓取当前屏幕上的所有文字与位置坐标（节点模式直接读取页面控件与坐标；识图模式自动静默截取整屏并识别文字坐标），联网翻译后**直接在原文字位置上覆盖显示译文**，再次轻点屏幕任意位置即可关闭译文层恢复原页面。
   - **长按悬浮球（0.5秒）**：直接在 `EN→ZH`（英译中）和 `ZH→EN`（中译英）之间切换，球面文字实时变化。
   - **双击悬浮球**：在 `节点`（适合网页、微信、普通App，免截屏极速）与 `识图`（适合PDF、图片，自动全屏截图OCR）模式间切换。
3. **APK 体积大幅瘦身**：启用了 `isMinifyEnabled = true`、`isShrinkResources = true` 与 ABI 分包（仅保留手机主流 `arm64-v8a`），剔除冗余库体积。
